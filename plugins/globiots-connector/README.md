# @universal-iot/plugin-globiots-connector

> Globiots Cloud LoRa Service Connector & Forwarder Plugin.

## Features
- **Globiots Cloud Integration**: Ingests uplink telemetry directly from Globiots Cloud LoRa service.
- **Bi-directional Uplink Forwarding**: Supports auto-forwarding decoded and raw uplinks back to Globiots cloud endpoints.
- **Customer Code & Tenant Mapping**: Accurately maps `customerCode` to platform tenant contexts.

## Standalone Development
```bash
npm install
npm run build
npm test
npm run pack
```
